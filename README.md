# Каталог книг на Docker Compose

Небольшое приложение из **трёх контейнеров**: Nginx с фронтендом, Flask API и PostgreSQL. При первом запуске база создаёт таблицу `books` и добавляет примеры книг. Кнопки **«Все книги»** и **«Прочитанные»** запрашивают данные из PostgreSQL через API. Форма добавляет новую книгу в базу.

## Запуск

Нужны Docker и Docker Compose. Из этой папки выполните:

```bash
docker compose up --build -d
```

Откройте [http://localhost:8080](http://localhost:8080). Для просмотра состояния:

```bash
docker compose ps
docker compose logs -f
```

Остановка без удаления данных:

```bash
docker compose down
```

Полная очистка, включая том с книгами:

```bash
docker compose down -v
```

Если порт 8080 занят, измените `8080:80` в `docker-compose.yml` на свободный порт, например `8081:80`.

## API

Браузер обращается к API через Nginx по тому же адресу `localhost:8080`:

| Метод | Путь | Действие |
| --- | --- | --- |
| GET | `/api/books` | Все книги |
| GET | `/api/books?status=read` | Только прочитанные книги |
| GET | `/api/stats` | Число всех и прочитанных книг |
| POST | `/api/books` | Добавить книгу, JSON: `{"title":"Название","author":"Автор","is_read":false}` |
| GET | `/api/health` | Проверка API и соединения с БД |

Данные PostgreSQL сохраняются в именованном томе `postgres_data`. Скрипт `db/init.sql` выполняется при создании нового тома.

В исходной методичке описаны четыре контейнера с отдельным веб-сервисом по индивидуальному варианту. Здесь реализовано ровно три контейнера по условию задания; обе кнопки работают с внутренней базой данных.
