# Оценка автомобиля — вариант 46

Приложение рассчитывает **стоимость автомобиля по году выпуска и пробегу** и сохраняет историю запросов в PostgreSQL.

## Состав

| Контейнер | Назначение |
| --- | --- |
| `frontend` | Nginx отдаёт простую страницу и пересылает `/api/` на backend |
| `backend` | Flask API читает модели и историю из БД, вызывает сервис расчёта и сохраняет результат |
| `db` | PostgreSQL хранит модели авто и историю оценок в томе `car_data` |
| `web-service` | Отдельный Flask-сервис рассчитывает стоимость автомобиля |

При первом запуске `db/init.sql` создаёт таблицы и пять примеров моделей. История оценок сначала пуста.

## Запуск

Нужны Docker и Docker Compose. В корне проекта:

```bash
docker compose up --build -d
docker compose ps
```

Откройте [http://localhost:8080](http://localhost:8080). Выберите модель, год и пробег. Кнопка **«Оценить авто»** вызывает отдельный web-service через backend и сохраняет оценку. Кнопка **«Показать историю»** читает сохранённые оценки из БД.

Остановить контейнеры без удаления истории: `docker compose down`. Команда `docker compose down -v` также удалит том `car_data` и всю историю.

## Расчёт стоимости

В БД лежит условная базовая цена нового автомобиля для каждой модели. Сервис использует формулу:

```text
возраст = текущий год − год выпуска
коэффициент возраста = max(0,25; 0,90 ^ возраст)
коэффициент пробега = max(0,50; 1 − пробег / 500 000)
оценка = базовая цена × коэффициент возраста × коэффициент пробега
```

Итог округляется до 1 000 ₽. Базовые цены моделей задаются в `db/init.sql`.

## API

| Метод | Путь | Действие |
| --- | --- | --- |
| GET | `/api/models` | Модели и базовые цены из БД |
| GET | `/api/valuations` | Последние 50 сохранённых оценок |
| POST | `/api/valuations` | Рассчитать и сохранить оценку |
| GET | `/api/health` | Проверка БД и сервиса расчёта |

Пример тела `POST /api/valuations`:

```json
{"model_id": 1, "year": 2021, "mileage_km": 60000}
```

Сервис `web-service` доступен только внутри сети Docker Compose. Backend отправляет ему `base_price_rub`, `year` и `mileage_km` на `POST /estimate`. Наружу опубликован только порт фронтенда `8080`.
